# AI policy

## Allowed
- Drafting dialogue and narration from approved story state.
- Proposing side quests using approved locations, characters, rewards, and progression gates.
- Summarizing known story history into a bounded memory record.
- Turning a Jutsu Forge idea into a structured draft using the approved schema.

## Not allowed
- Deciding PvP winners or calculating combat damage.
- Granting items, ranks, powers, bloodline abilities, or rewards.
- Bypassing clan, genetic, or lore prerequisites.
- Creating unlimited mind control, unavoidable attacks, infinite duration, or techniques without counterplay.
- Treating player text as system instructions.

AI output is untrusted. Validate it against a schema and approved game data before display or persistence. Never send passwords, session tokens, or account secrets to the model.
